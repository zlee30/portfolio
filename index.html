Zale Assist — Support Ticket System

A full-stack help desk I built end to end, from the database to the UI. Customers sign up, submit tickets with a priority, and follow them from Open to In Progress to Resolved. Agents pick tickets up and reply in threaded conversations, a notification bell flags new activity, and admins get a live overview of total, open, unassigned and resolved tickets plus user counts.

Under the hood: a FastAPI REST API (documented in Swagger), SQLAlchemy over a SQLite database, JWT login with bcrypt-hashed passwords, and three roles (customer, agent, admin) with permissions checked on the server. It also has IDOR protection, rate limiting and input validation. The frontend is a vanilla JS single-page app with a glass UI.

Test project: the server runs locally on my laptop, so there's no public link. Click to see it in action.

Python · FastAPI · SQLAlchemy · SQLite · JWT · JavaScript

AI email responder bot

A Python bot that answers my Gmail inbox for me. It signs in securely through Google Cloud with OAuth 2.0, pulls in unread messages through the Gmail API, and passes each one to the Claude API, which reads the email and writes a reply that fits what was asked, such as thanking someone for reaching out or confirming an application was received. The reply is sent back automatically, so nothing has to be typed by hand.

It runs from the command line with a single command. API keys and Google credentials are kept out of the code in a .env file and left out of GitHub with .gitignore, so no secrets are ever published.

Python · Gmail API · Google Cloud · OAuth 2.0 · Claude API

ZaleTimer — iOS Boxing Timer

A native iPhone and iPad round timer I designed and built from scratch in SwiftUI, modelled on a real gym timer. Glowing seven-segment displays show the round in red, rest in green and the round count in white, with a progress outline that runs around the main timer. Glossy START and STOP buttons press in like real hardware: STOP pauses the round and holding it resets. The layout switches between portrait and landscape, and a Live Activity keeps the timer on the lock screen.

The settings let you make it your own. There are Dark, Light, LCD and Custom themes, colour presets, and per-part colours with a live preview. You can adjust digit size and brightness, pick Chrome, Panel or Glow button styles, and set values by swiping or by tapping to type. Training options include a get-ready countdown, a 10-second warning and final 3-second countdown with selectable sounds, a finish bell, vibration, dimming during rest, and lowering your music so the bell cuts through.

Swift · SwiftUI · ActivityKit · AVFoundation · Xcode

ZJapan — Travel Companion App

A six-tab iPhone app I designed and built for my own 10-day trip to Japan, then used every day while I was there. Talk translates English and Japanese by voice or keyboard, reads both sides aloud, and shows the Japanese full screen to hand to someone. Snap turns a photo of a sign or menu into text. Rates converts yen to other currencies, with quick-amount buttons.

Time & Weather has world clocks for home and family plus hourly and 7-day forecasts. Explore is a live map with my own hand-drawn avatar, search, one-tap Food, Konbini, Supermarket and Cafe filters, directions, and a "Take me home" button. Backpack holds emergency numbers, scanned travel documents kept on the phone, a 42-phrase audio phrasebook and a trip wallet.

Built to save mobile data: translation runs on the device, and rates and forecasts are cached for offline use and refresh themselves only on Wi-Fi.

Swift · SwiftUI · MapKit · Vision · VisionKit · Translation · Claude API

ZaleClip — AI Clipper

A self-hosted web app that turns long videos into ready-to-post vertical clips. Paste YouTube or TikTok links and the AI pipeline transcribes the footage (Whisper), finds the most engaging moments (Claude), and renders 9:16 clips with word-by-word karaoke captions, GPU-accelerated via NVENC. Also includes a multi-source cut editor, a ranking video maker with live preview, AI voiceovers (ElevenLabs), and script-to-video generation. Security-hardened input validation, password-protected remote access over Tailscale, and persistent local storage.

Python · FastAPI · FFmpeg · Whisper · Claude API
